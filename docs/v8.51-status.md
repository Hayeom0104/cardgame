# v8.51 기준선 및 구현 현황

기준: 오너 제공 `Deckout_Design_Doc_v8.51.md`, 원격 브랜치
`claude/new-session-m5fo91`의 `1c82595`를 비교했다.

## 이미 연결된 콘텐츠

- 캐릭터: 스타터 루야 외 일반 로스터 13명.
- 확장팩 v1: 스킬 60장, 패시브 30장, 이벤트 4종.
- 월드 1: 일반 고블린 역할별 행동, 전리품꾼 소환,
  보스 HP 450/공격 20/방어 8/속도 96, HP 55%에서 2페이즈.
- 전쟁북 준비 상태를 통한 다음 대돌진 예고.

확장팩은 `seed_constants` → `seed_expansion`으로, 월드 1 변경은
`publish`의 구버전 시드 감지 → `apply_if_legacy_seed`로 연결된다.
새 콘텐츠를 중복으로 추가하지 않는다.

## 이번 기준선 교정

1. 전쟁북 준비의 countdown 정의에 잘못 들어간 stack_cap=1을 NULL로
   교정했다. 이 오류는 최신 시드의 발행 자체를 막고 있었다.
2. 확장팩 고등급 카드 7장의 원본 비용을 4에서 3으로 정리했다.
   기존 발행값은 이미 3이었으므로 정상적인 기존 게임 밸런스는 유지된다.
3. 발행 단계의 비용 상한 자동 보정을 제거했다. 원본과 발행값을 일치시키고
   향후 잘못 작성된 비용은 공용 검증에서 거절한다.
4. Batch 1 설명의 과거 7명 상태를 현재 13명으로 정리했다.
   옛 12명 기준 비율은 역사적 기준으로 명시하고 검증 플래그는 false를 유지한다.

## 다음 단계의 경계

- 튜토리얼: 현행 난이도를 유지한다. 노드 수·대사·전용 이벤트·보상 시점·
  새 보스 기믹은 오너 최종안 전까지 확정하지 않는다(v8.51 §4.2).
- 임시 카드 봉인·공용 전투 게이지: Phase 2 계획이며 이번 기준선 커밋의
  구현 완료 항목이 아니다. 반환 조건과 리셋 정책, 공용 연산자/저장 구조를
  마련한 후 적용한다. 런 덱에서 카드를 삭제하는 대체 구현은 금지한다.
- 월드 1 카드 강탈·전쟁북 0/4는 보류(§6.2). 현행 준비 상태 기반 예고와
  혼동하지 않는다.
- Batch 1 재활성화는 로스터 승인과 전용/원소 공유 카드 관계 확정 후에 한다.
- UI 배치 변경 및 월드 2~4 대규모 개편은 이번 작업에 포함하지 않는다.

실행 중 서버/DB는 변경하지 않았다. 검증은 별도 테스트 DB에서 수행한다.
