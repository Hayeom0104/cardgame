# Deckout 덱·수집·성장·월드 1 개편 인수 문서

사용자가 전달한 개편 요청을 기준으로 원본 전체 프로젝트를 수정했습니다.
설계 문서 v8.51은 기존 구조를 확인하는 자료로, 튜토리얼 v8.52는 별도 기획안으로 취급했습니다.
튜토리얼 분기·카드 봉인·전쟁북 게이지·월드 2~4 리메이크는 이번 요청의 구현 항목으로 확대하지 않았습니다.

## 적용한 규칙

| 영역 | 구현 내용 |
|---|---|
| 덱 | 캐릭터별 18장. 기본 공격 6장과 기본 방어 5장 고정. 나머지 스킬 7장은 카드별 장수로 편성 |
| 저장 | 계정/캐릭터마다 덱 하나 저장. 파티 자리 순서가 바뀌어도 해당 캐릭터의 저장 덱 사용 |
| 중복 편성 | 같은 스킬 최대 7장. 한 번 해금하면 여러 장 편성 가능. 보유 중복 수량과 분리 |
| 자동 편성 | 해금된 사용 가능 스킬을 공격/방어/회복 등의 역할별로 선택해 초안 구성 및 저장 |
| 편집 UI | 카드 선택 → 장수 선택 → 7장 완성 → 저장하고 다음. 스킬 비우기, 목록 페이지, 다시 편성 제공 |
| 신규 캐릭터 | 기존 스킬 묶음을 함께 해금. 이미 가진 카드의 강화 단계와 재료는 변경하지 않음 |
| 기존 계정 | 업그레이드 명령과 허브/준비 화면 진입 시 보유 캐릭터의 기본 스킬을 소급 지급 |
| 일반 보상/상점 | 기존 해금 카드 중심 규칙 유지 |
| 체험 이벤트 | 수상한 행상의 화염 강타를 해당 모험에만 추가. 수령 캐릭터 선택과 호환 속성 검사 연결 |
| 성장 | 기존 성급, 카드 0~5 강화, 중복 조각/와일드카드, 장비 획득·구매·장착·강화 유지 |
| 장비 표시 | 장착 캐릭터 이름, 강화 전후 실제 능력치와 증가량, 강화석 비용 표시 |
| 보스 | 월드 1의 대족장/대주술사/철갑대장 중 하나를 매 도전 무작위 선정. 연속 중복 허용 |
| 보스 예고 | 파티·덱·확정 화면에서 표시. 준비 취소/재진입으로 재추첨되지 않음. 출발 시 런에 고정 |

동일 스킬 7장 제한, 캐릭터별 저장 덱 하나, 지급 스킬 목록, 신규 보스 수치는 제안 내용을 바탕으로 정한 구현 기본값입니다.
실제 플레이 피드백에 따라 조정할 수 있습니다. 기본 카드 11장의 비중을 줄이는 리메이크는 적용하지 않았습니다.

## 캐릭터별 지급 스킬

전용 카드 체계를 만들지 않고 기존 카드 ID를 연결했습니다.
공유 스킬은 같은 속성 또는 무속성 규칙으로 계속 사용합니다.
루야는 튜토리얼의 기존 화염참 7장 구성을 보존합니다.

| 캐릭터 | 지급 스킬 |
|---|---|
| 루야 | 화염참 |
| 이그니스 / 파이라 | 타오르는 불씨, 불꽃 장막, 응급 처치 |
| 아쿠엘 / 마레아 | 물결 베기, 물의 장막, 물의 치유 |
| 리라 | 유리 파편, 파도 수호, 물의 치유 |
| 테라돈 / 실바 | 암석타, 석갑, 응급 처치 |
| 벤투스 / 제피르 | 질풍베기, 엄호, 응급 처치 |
| 움브라 / 녹티스 | 그림자 칼날, 엄호, 응급 처치 |
| 루멘 / 솔렌 | 섬광, 엄호, 온기의 빛 |

설정 원본: `config/14_덱개편.toml`.
이미 발행된 콘텐츠 값은 기존 방식대로 DB/관리자 대시보드에서 관리합니다.
설정 파일을 고친 것만으로 기존 런의 값이 바뀌지 않습니다.

## 신규 보스

| 보스 | HP / 공격 / 방어 / 속도 | 패턴 |
|---|---|---|
| 고블린 대주술사 | 200 / 12 / 3 / 88 | 쇠약 주술 → 저주 폭발 → 주술 재정비 |
| 고블린 철갑대장 | 240 / 14 / 8 / 84 | 철갑 방어 → 방패 강타 → 갑옷 정비 |

두 보스 모두 HP 50%에서 2페이즈로 전환합니다.
대주술사는 단일 속도 감소에서 광역 방어력 감소로 바뀝니다.
약화는 짧은 지속시간을 가지며, 정화 카드가 없어도 방어하면서 넘길 수 있습니다.
철갑대장은 2페이즈에서 방어와 강타가 강화됩니다. 정비 때 방어력 감소가 적용되어 공격할 기회가 생깁니다.
전투 엔진에 보스 ID별 분기를 추가하지 않고, 기존 조건·상태·효과 연산자와 콘텐츠 테이블로 구현했습니다.
신규 보스 전용 일러스트는 기존 렌더러의 대체 이미지를 사용합니다.

기존 대족장(450 / 20 / 8 / 96)의 수치와 소환·전쟁북 패턴은 유지했습니다.
기본 지급 스킬만 사용하는 간단한 자동 플레이어의 성급 1·무장비 30회 시험에서는 대족장 클리어가 없었습니다.
상점 수련 장비 T0를 갖춘 추가 시험에서도 같은 자동 플레이어는 클리어하지 못했습니다.
따라서 **세 보스의 초반 체감 난도가 동등하다는 검증은 아직 성립하지 않습니다.**
특히 기존 대족장의 초반 난도는 실제 플레이에서 먼저 확인할 항목입니다.
이 결과는 특정 덱의 불가능성을 증명하는 것은 아니며, 실버·보상·성장을 포함한 전체 모험의 클리어율도 아닙니다.

## 코드와 데이터

- `app/engine/loadouts.py`: 장수 검증, 저장 덱, 기본 스킬 지급과 소급 적용.
- `app/api/deck_editor.py`: 장수 편집 및 목록 페이지.
- `app/engine/lifecycle.py`: 정확한 장수 반영, 저장 덱 사용, 런 보스 스냅샷.
- `app/engine/boss_selection.py`: 준비 중 보스 유지와 안내.
- `app/content/deck_refresh.py`: 추가 콘텐츠와 지급 스킬 참조 검증.
- `app/api/screens.py`, `handlers.py`, `app/render/panels.py`: 준비·뽑기·덱·장비 표시.
- `app/engine/nodes.py`: 고정된 보스 조우, 체험 카드 수령.
- `app/db/connection.py`, `schema.sql`: 스키마 8 → 9.
- `app/cli/upgrade_deck_refresh.py`: 기존 콘텐츠를 복사해 추가 기능만 발행하는 업데이트 명령.

추가 테이블은 `character_decks`, `boss_previews`입니다.
`runs.boss_encounter_id`가 추가됩니다.
기존에 진행 중이던 런은 이전 콘텐츠 버전과 덱을 유지합니다.
오래된 준비 초안의 스킬 장수가 7장이 아니면 편집 화면에서 완성해야 합니다.
콘텐츠 버전이 바뀌면 새 버전 기준의 보스 미리보기를 사용합니다.

원본 테스트에서도 발견된 Windows CP949/Git UTF-8 불일치는 `github_sync.py`의 Git 출력 인코딩을 명시해서 수정했습니다.

## 설치와 기존 DB 업데이트

새 설치:

```bash
pip install -e ".[dev]"
python -m app.cli.bootstrap --db deckout.db
python -m app.cli.check_content --db deckout.db
pytest
```

기존 운영 DB:

1. 서비스를 중지하고 SQLite DB를 백업합니다.
2. 수정된 코드와 의존성을 설치합니다.
3. 아래 명령에 실제 운영 DB 경로를 넣어 실행합니다.
4. 콘텐츠 검사 후 기존 실행 방식으로 서비스를 재시작합니다.

```bash
python -m app.cli.upgrade_deck_refresh --db /path/to/existing/deckout.db
python -m app.cli.check_content --db /path/to/existing/deckout.db
```

기존 DB 업데이트에는 새 전용 명령을 사용합니다. `bootstrap --force`는 전체 기본 콘텐츠를 다시 시드하므로 기존에 관리자가 조정한 콘텐츠를 유지하려는 목적과 맞지 않습니다.
원본 코드로 만든 스키마 8 DB에 실제로 업그레이드를 적용해, 기존 콘텐츠 지문·진행 중인 36장 파티 덱·성급 보존과 신규 보스 3종 발행을 확인했습니다.

Central Bot 연결 구조와 Discord 명령은 그대로입니다. 실제 운영 서버에 배포하거나 메시지를 보내지는 않았습니다.

## 검증

최종 자동 테스트 결과는 함께 제공한 `VERIFICATION.md`를 참고하세요.
새 테스트는 정확한 3/2/2 장수 반영, 잘못된 카드/장수 차단, 재지급 멱등성, 파티 순서 변경, 목록 페이지,
보스 미리보기 유지, 임시 체험의 영구 해금 방지, 페이즈/실제 효과, 이전 DB 마이그레이션과 스냅샷 보존을 포함합니다.

실제 렌더러로 만든 화면은 `docs/previews/`에 있습니다.
장비의 여러 능력치가 잘리지 않도록 두 줄로 표시하고, 덱 카드 이름을 하단에도 표시했습니다.
Discord 컴포넌트 흐름은 로컬 핸들러 테스트로 검증했으며, 실제 Central Bot/Discord 서버에서의 전송과 클릭 검증은 남아 있습니다.

신규 보스 시뮬레이션은 루야·테라돈 성급 1, 무장비, 카드 강화 0, 기본 지급 스킬, 자동 편성,
보스 진입 시 전원 최대 HP로 진행했습니다. 추가 뽑기 스킬·연구·패시브·모험 중 보상은 사용하지 않았습니다.

| 보스 | 클리어 | 평균 라운드 |
|---|---:|---:|
| 고블린 대주술사 | 30 / 30 | 24.6 |
| 고블린 철갑대장 | 30 / 30 | 35.2 |

이는 동작 확인을 위한 제한된 자동 플레이 결과입니다.
신규 보스의 최종 난도, 기본 11장 비중의 재미, 실제 모험 종료까지 걸리는 시간은 사람이 플레이하며 추가 조정해야 합니다.
