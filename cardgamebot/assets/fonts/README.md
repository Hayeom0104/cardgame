# 폰트

이미지 렌더링(§11)에 한글 글리프가 있는 TTF/OTF 가 필요합니다.
이 디렉터리에 아래 이름으로 넣으면 시스템 폰트보다 우선 사용됩니다.

- `NotoSansKR-Regular.ttf`
- `NotoSansKR-Bold.ttf`  (선택 — 없으면 Regular 로 대체)

없으면 `render/base.py` 의 후보 목록을 따라 시스템 CJK 폰트를 찾습니다.

이모지는 컬러 이모지 폰트가 없으면 두부(□)로 깨지므로, 렌더러는 이미지에
이모지를 그리지 않고 한글 라벨을 씁니다. 디스코드 본문 텍스트에서는 이모지가
정상 표시됩니다.
